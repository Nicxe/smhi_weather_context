# Security policy

## Supported versions

Security fixes are provided for the latest stable release. A fix may first be
made available as a beta when live Home Assistant or SMHI validation is needed.

## Reporting a vulnerability

Use GitHub private vulnerability reporting once the repository is published.
Until then, report vulnerabilities privately to the maintainer. Do not include
precise coordinates, Home Assistant URLs, access tokens, credentials, raw cache
files, or unredacted diagnostics in a public issue.

Include the affected version, the user-visible impact, and the smallest safe
reproduction available. Public disclosure should wait until a fix or an agreed
mitigation is available.

## Dependency response

Critical runtime vulnerabilities are assessed within 48 hours and targeted for
remediation within seven days. High-severity runtime vulnerabilities are
assessed within seven days and targeted for remediation within 30 days.
Build-only findings without an upstream fix must be documented with an owner,
an expiry date, and a planned re-review.
